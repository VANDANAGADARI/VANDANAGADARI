# Vandana Gadari — Geospatial Portfolio

A tab-based, responsive portfolio built with plain HTML, CSS and JavaScript.

## Structure

- `index.html` — page structure
- `css/style.css` — design and responsive layout
- `js/data.js` — all editable portfolio content
- `js/app.js` — tab navigation, rendering and interactions
- `assets/images/profile.jpg` — add your real profile photo here
- `assets/images/maps/` — add map images here
- `assets/documents/resume.pdf` — add your current resume
- `assets/documents/certifications.pdf` — add your certificates PDF

## Updating the portfolio

Most regular updates only require editing `js/data.js`.

- Change `profile.currentStatus` to update your current work/interests.
- Add objects to `projects` for new projects.
- Add objects to `maps` for new maps.
- Update `documents` when you add your resume/certification file.
- Add skills inside `skills`.

The HTML does not need to be edited for normal content updates.
